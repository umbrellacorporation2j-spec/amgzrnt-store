AMGZRNT STORE — الإصدار V3.8

التغييرات:
- زر «تثبيت» في صفحة تفاصيل التطبيق يبدأ تجهيزاً مرئياً بموجات سائلة متحركة، بدلاً من شريط تحميل تقليدي.
- مدة الحركة تختلف حسب التطبيق باستخدام مدد 17 و12 و15 و10 و4 و9 و6 و3 ثوانٍ، وتتكرر حسب معرّف التطبيق.
- بعد اكتمال الحركة يتحول الزر مباشرة إلى «فتح التطبيق»، والضغط عليه يفتح رابط التطبيق في نفس علامة التبويب.
- الضغط على اسم المطور يغلق صفحة تفاصيل التطبيق أولاً ثم يفتح صفحة المطور كصفحة مستقلة.
- لم يتم تغيير مستندات التطبيقات أو بيانات Firebase أو قواعد Firestore.

ملاحظة مهمة:
المتجر لا يستطيع تثبيت موقع خارجي فعلياً نيابةً عن المستخدم. حركة الموجات هنا مرحلة تجهيز مرئية داخل المتجر، وبعدها يفتح الموقع. إذا كان الموقع يدعم PWA يمكن تثبيته من قائمة المتصفح.

طريقة التحديث:
1) احتفظ بنسخة احتياطية من ملفات الاستضافة الحالية.
2) فك ضغط ZIP وارفع جميع الملفات الـ14 مع استبدال ملفات الإصدار السابق.
3) لا تحذف بيانات Firebase ولا تستبدل قواعد Firestore.
4) افتح رابط HTTPS وحدّث الصفحة. إذا بقيت نسخة قديمة، أغلق التبويب وافتحه مجدداً لتحديث Service Worker.

التحقق:
تم فحص بنية ZIP ومرور JavaScript المضمن عبر فحص الصياغة محلياً. لم يتم إجراء اختبار حي على استضافة المتجر أو Firebase أو متصفح الهاتف.


إصلاح V3.8: توحيد مسار تجهيز التطبيق وفتح الرابط، إصلاح مؤقت الموجات، ومعالجة ظهور الإشعارات خلف الصفحات. مدة الموجات شكلية للتجهيز وليست تنزيلًا فعليًا لتطبيق خارجي.


تحسين إصدار V3.8 الرسمي:
- زر التثبيت يعرض موجات تجهيز شكلية بالمدة المحددة لكل تطبيق.
- بعد انتهاء الموجات، يستخدم زر الفتح نفس الرابط الذي تم التقاطه عند بداية العملية؛ لا يعيد البحث عن التطبيق أو قراءة سجل جديد.
- فتح الموقع يعتمد على رابط http/https المسجل فقط، ولا يشترط أن يكون الموقع PWA أو أن يملك manifest أو Service Worker.
- الموجات ليست تنزيلًا فعليًا لملفات الموقع ولا تثبيتًا لتطبيق مستقل؛ هي واجهة تجهيز ثم فتح للرابط.


V3.8: توحيد زر التثبيت في صفحة التطبيق والنافذة السفلية، وإظهار تقدم موجي بصري، ثم فتح رابط الموقع الأصلي في نفس علامة التبويب. مدة الموجات محاكاة مرئية وليست تنزيلًا فعليًا لملفات الموقع. تم إصلاح رابط صفحة المطور ورفع طبقتها فوق صفحة التطبيق.
